# personal-finance-manager
This is a simple console-based Income and Expense Tracker written in Python.
It allows users to record incomes and expenses with a purpose and date.
The program uses lists to store entries as tuples of amount, date, and purpose.
Users can interact with the system using a menu-driven interface.
Incomes might include salary, bonus, etc., while expenses can be food, rent, etc.
It automatically captures the current date for each transaction using datetime.
Users can view a report summarizing their financial activity at any time.
The report includes total income, total expense, and remaining balance.
Each entry is displayed clearly for both income and expenses.
The program runs in a loop until the user chooses to exit gracefully.

Features
Add income entries with amount, purpose, and date.
Add expense entries similarly with detailed context.
Auto timestamping of each transaction using current date.
Generates a comprehensive financial report.
Displays total income, total expense, and balance.
Lists all individual income and expense records.
Simple and user-friendly menu-driven interface.
Uses basic data structures (lists and tuples) for tracking.
Prevents invalid menu input with an error message.
Entire program runs without external libraries (except datetime).


Steps to Run and Use the Program 
Open a code editor (like VS Code) or any Python IDE.
Copy and paste the entire code into a new .py file (e.g., tracker.py).
Save the file and run the script using Python (Python 3 recommended).
A menu will appear with options to add income, add expense, view report, or exit.
Choose option 1 to add an income entry and provide amount and purpose.
Choose option 2 to add an expense entry and provide amount and purpose.
Each entry is recorded with the current date automatically.
Choose option 3 to view a detailed financial report.
The report will show total income, expenses, balance, and all entries.
Choose option 4 to exit the program safely.
